Fase 1

Instalación de LocalAI.

Instalación

Instalación del motor de LLMs LocalAI en la máquina local con Ubuntu. El script descarga una imagen Docker del software y un LLM pequeño, Qwen3.8-4B en Q4, para pruebas. También descarga el backend llama.cpp y lo configura para la gráfica de 4 GB de este portátil modesto.

Al terminar queda accesible en local en http://127.0.0.1:8080.

No está configurado con clave de API ni securizado. Cuidado en entornos productivos.

El script crea su carpeta dentro del directorio personal, o usa LOCALAI_DIR si está definida. No arrastra rutas de otra máquina. Ejecución en el equipo.

Descargar install_localai.sh
