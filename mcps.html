Fase 3

Instalación de los MCPs.

El producto es MVP Audit Orchestrator V2. Esta instalación añade dos MCP al agente.

https://github.com/agentef0ns1/MVP-audit-orchetrator-v2.git

Descarga

En un entorno limpio, el repositorio se descarga así.

git clone https://github.com/agentef0ns1/MVP-audit-orchetrator-v2.git
cd MVP-audit-orchetrator-v2

Instalación

La instalación sigue el README del repositorio. Hace falta Python 3.11 o superior y Docker Compose v2. ./setup.sh crea el entorno, la imagen de Kali, las bases del orquestador y la configuración de los dos MCP.

README 
./setup.sh

Los dos MCP

Orchestrator

Cuenta con dos bases de datos: una relacional, SQLite, y otra no relacional, Neo4j.

Atacante

Imagen Docker de Kali, con una cola de ejecución. Los comandos corren en segundo plano.
