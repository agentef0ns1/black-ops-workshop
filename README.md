# Workshop [black-ops]

Base del workshop para montar un entorno local en un portátil modesto con Ubuntu 26.04.1 LTS. Va por fases: LocalAI, agentes, MCPs, laboratorios y QA de métricas. El contenido y los scripts se amplían en este directorio.

Sitio estático. `index.html` está en la raíz.

Si se publica en GitHub Pages, la fuente es la rama y la carpeta `/ (root)`. No hace falta un workflow de Actions.

`.nojekyll` evita que Pages procese el sitio con Jekyll.
